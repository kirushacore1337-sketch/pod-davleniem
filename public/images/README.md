# Изображения сайта «Под Давлением»

Все фотографии сайта хранятся локально в `public/images/`. Не вставляйте внешние URL.

## Структура и точные имена файлов

```text
public/images/
├── hero/
│   └── hero-main.webp
├── services/
│   ├── tire-fitting.webp
│   ├── wheel-balancing.webp
│   ├── tire-repair.webp
│   ├── seasonal-tire-change.webp
│   └── tire-storage.webp
├── about/
│   ├── workshop-interior.webp
│   └── workshop-equipment.webp
├── promo/
│   └── promo-car.webp
├── pricing/
│   └── tires-stack.webp
└── gallery/
    ├── gallery-01.webp
    ├── gallery-02.webp
    ├── gallery-03.webp
    ├── gallery-04.webp
    ├── gallery-05.webp
    └── gallery-06.webp
```

## Что должно быть на фотографиях

| Путь | Содержание | Где используется / назначение |
|---|---|---|
| `hero/hero-main.webp` | Мастер работает с колесом автомобиля в современном шиномонтаже | Большое фоновое фото первого экрана |
| `services/tire-fitting.webp` | Монтаж или демонтаж автомобильной шины | Карточка «Шиномонтаж» |
| `services/wheel-balancing.webp` | Колесо на балансировочном станке | Карточка «Балансировка» |
| `services/tire-repair.webp` | Ремонт прокола автомобильной шины | Карточка «Ремонт шин» |
| `services/seasonal-tire-change.webp` | Сезонная смена комплекта колёс | Карточка «Сезонная замена» |
| `services/tire-storage.webp` | Аккуратно сложенные автомобильные шины | Для услуги «Хранение шин»; сейчас карточка использует CSS-заглушку |
| `about/workshop-interior.webp` | Общий вид помещения сервиса | Для страницы «О компании» |
| `about/workshop-equipment.webp` | Шиномонтажный и балансировочный станки | Для блока об оборудовании |
| `promo/promo-car.webp` | Автомобиль в тёмной студии или боксе с оранжевым светом | Фон рекламного баннера |
| `pricing/tires-stack.webp` | Стопка шин | Для оформления страницы цен |
| `gallery/gallery-01.webp` … `gallery-06.webp` | Шесть разных фотографий сервиса и работ | Шесть плиток галереи |

## Правила

- Имена — строго латиницей, строчными буквами, без пробелов.
- Используйте дефис `-` вместо пробелов.
- Расширение — `.webp` (именно так, маленькими буквами). Если фото у вас в JPG/PNG, конвертируйте его в WebP или поменяйте путь в коде.
- Не переименовывайте файлы произвольно: имена должны совпадать с таблицей и CSS.
- Оптимальный размер: главный баннер 1600–2000 px по ширине; карточки и галерея 900–1200 px по ширине. Старайтесь держать фотографии примерно до 300–500 КБ каждая.
- Для главного экрана выбирайте горизонтальный кадр 16:9 или шире; для карточек — горизонтальный 4:3.
- Не кладите фотографии в `src/` или `dist/`: исходные изображения добавляются в `public/images/`. Vite копирует их в сборку автоматически.

## Проверка

После добавления файлов запустите `npm run dev` и откройте сайт. Например, файл `public/images/hero/hero-main.webp` должен открываться по адресу `/images/hero/hero-main.webp`. После изменений выполните `npm run build`.
